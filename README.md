# 3D 模型的 AI 工作流程手册

一份给 3D 美术整理的 AI 工具实战参考，按生产流程组织——从概念设计到 Unity 集成，每个阶段该用什么 AI 工具，怎么用，注意什么，都在里面。

## 为什么写这个

AI 工具更新太快，每次想用都要重新搜索、对比、试错。索性把验证过的工具按工作流整理成册，需要时翻到对应章节就行。

## 看什么

主文档：[3D模型的AI工作流程手册.md](./3D模型的AI工作流程手册.md)

按生产流程分了六章 + 五个附录：

- **第一章** 前期设计 — 概念图、参考、多视图
- **第二章** 高模 — Image-to-3D、雕刻细节、硬表面
- **第三章** 低模 — 自动拓扑、减面 LOD
- **第四章** UV — 算法展开、批量处理
- **第五章** 材质贴图 — 颜色图、PBR 反推、无缝、ComfyUI
- **第六章** Unity 集成 — 导入规范、Shader、场景搭建
- **附录** 工具速查表、Prompt 库、脚本自动化、硬件配置、更新日志

## 适合谁看

主要技术栈是 Maya / 3ds Max / Blender + Substance + Unity 的 3D 美术。其他技术栈也可以参考，工具大多通用。

不适合找入门教程的人——手册默认你已经是熟练的 3D 美术。
